# Bibliographie et ressources techniques

Les ressources suivantes ont été consultées pour vérifier certains éléments d'implémentation MATLAB/Simulink et de traitement du signal.

1. **MathWorks — Filtrage et mise en forme d'impulsion**  
   Documentation MATLAB/Communications Toolbox sur le filtrage, le filtre adapté et les filtres en cosinus surélevé.  
   https://fr.mathworks.com/help/comm/filtering.html

2. **MathWorks — Hamming Decoder**  
   Documentation du bloc Simulink de décodage de Hamming et rappels sur le codage de Hamming.  
   https://fr.mathworks.com/help/comm/ref/hammingdecoder.html

3. **MathWorks — `uifigure`**  
   Documentation de référence utilisée pour la construction de l'interface graphique MATLAB de l'application finale.  
   https://fr.mathworks.com/help/matlab/ref/uifigure.html

Ces ressources complètent le sujet du TP fourni dans `docs/TP_2026-2027_Simulink-2.pdf`.
