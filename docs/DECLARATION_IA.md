# Déclaration d'utilisation de l'IA

Des outils d'intelligence artificielle ont été utilisés comme assistance pour :

- relire et reformuler certaines explications ;
- aider au débogage de scripts MATLAB/Simulink ;
- proposer une organisation de l'application interactive ;
- améliorer la présentation et la documentation du dépôt.

Les choix techniques, les simulations, les résultats et leur validation ont été vérifiés à partir des scripts MATLAB/Simulink du projet et des consignes du TP.

Cette déclaration peut être adaptée selon les exigences de l'enseignant.
