# Guide d'utilisation

## Prérequis

- MATLAB
- Simulink
- DSP System Toolbox

## Lancement

1. Cloner ou télécharger le dépôt.
2. Ouvrir MATLAB dans le dossier racine du projet.
3. Exécuter :

```matlab
app_tp_arborescence
```

L'application utilise les scripts `.m` et modèles `.slx` présents à la racine du dépôt.

## Utilisation

L'interface suit les parties du TP :

- P2 : codage de source
- P3 : chaîne de base
- P4 : Hamming
- P5 : QPSK
- P6 : RRC
- P7 : canal à deux trajets

Pour chaque étape, l'application peut :
- exécuter le script associé ;
- afficher les figures obtenues ;
- afficher une interprétation ;
- lancer un test si demandé ;
- ouvrir le modèle Simulink associé.

## Remarque

Les fichiers `.slxc`, `slprj/` et les autosauvegardes ne sont pas nécessaires au fonctionnement du projet.
